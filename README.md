# Portfolio

A customizable personal portfolio built with React and Vite. It includes responsive sections for an introduction, expertise, selected work, experience, metrics, and contact, plus scroll and hover effects.

## Quick start

```bash
npm install
npm run dev
```

## Customize

1. Replace the sample text in `src/main.jsx` with your name, role, biography, skills, projects, experience, and metrics.
2. Update the email and LinkedIn links in `src/main.jsx`.
3. Replace `public/profile-placeholder.svg` with a portrait you have permission to use, then update the image path and alt text.
4. Update the title and description in `index.html`.
5. Adjust the colors and section backgrounds in `src/styles.css`. Background photos are loaded from Unsplash URLs; replace them with images you have permission to use or remove the image layers.
6. Search the repository for `Your Name`, `your.email@example.com`, and `XX` to find remaining sample values.

## Build

```bash
npm run build
npm run preview
```

## Deploy

Import the repository into Vercel as a Vite project. The build command is `npm run build` and the output directory is `dist`.
